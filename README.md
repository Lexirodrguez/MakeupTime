Bienvenido a MakeupTime, un sitio web educativo e informativo dedicado al fascinante mundo del maquillaje y el cuidado de la piel.

Paso a paso para ver el proyecto

1. Descargar el Proyecto desde el enlace de github

2. Abrir el Proyecto en el Navegador
   Abrir el archivo "Home", haciendo doble click sobre el y escogiendo el navegador de preferencia para visualizar la pagina web

3. Navegar por el Sitio
Una vez abierto el sitio en el navegador, usa el menú de navegación superior para moverte por las diferentes secciones (Home, Tendencias, Dupes, Suscripciones)

Home: Introducción, comparación de marcas y rutina básica de preparación de la piel.
Tendencias: Últimos looks que están marcando tendencia (videos incluidos sobre los ejemplos)
Dupes: Tabla comparativa de productos de alta gama vs. sus alternativas económicas con sus respectivos precios aproximados.
Suscripción: Formulario de Suscripción a la pagina web
